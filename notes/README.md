# notes/

Your own derivations and summaries, keyed to the books. These are public (unlike corpus/),
and they are what the `search` tool will cite when a reader doesn't own the book.

One file per topic, e.g. `greeks.md`, `parity.md`, `binomial.md`. Cite the section you
derived it from: "(Hull 9e §19.6, p. 405)". Write them as you fill in the engine; the
act of writing the note is the proof you understood the function you just made pass.
